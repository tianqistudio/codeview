# 序映 · SNView

导入清单，逐条出码。无需安装的单文件网页工具，支持在浏览器中查看 SN、生成条形码和二维码，并核对同一行的其他字段。

[在线使用](https://tianqistudio.com/work/SNView) · [备用入口](https://tianqistudio.com/tools/SNView) · [下载离线版](https://github.com/tianqistudio/snview/releases/latest)

<a id="功能"></a>

## 主要功能

- 自动识别常见 SN 表头；多个候选列可手动选择。
- 提供 Code 128 条形码、二维码和纯文字图片。
- 保留 SN 原文、前导零、顺序和重复项，不自动补号。
- 左右字段可通过箭头或表头下拉框选择，支持独立条码和字段变化提醒。
- 跟随系统浅色、深色主题；条码区域保持白底。
- 导入数据在浏览器本地处理，不回写源表。

<a id="使用"></a>

## 安装与使用

1. 在线打开工具，或从 Releases 下载 HTML 文件后用浏览器打开。
2. 导入 Excel、CSV、TXT、TSV，或粘贴表格内容。
3. 核对工作表、SN 列与数据起始行，点击「开始」。
4. 逐条切换条码，结合左右字段核对；需要时下载当前 SN 的 PNG 图片。

<a id="构建"></a>

## 开发与测试

构建需要 Python 3，以下命令在项目根目录运行；使用生成的网页不需要 Python 或 Node.js。

```sh
python tools/sn-viewer/refine.py
```

生成文件位于 `交付/SN连续出码/SN_连续出码工具_v1.2.html`。`source/` 保存生成基线，`tools/sn-viewer/` 保存生成器、样式、图标和交互代码；修改后重新构建。

<a id="注意事项"></a>

## 使用边界

Excel 中以数值保存的长编号可能已丢失精度，工具无法恢复原始数字。建议源表将 SN 保存为文本。切换页面不代表扫码成功，请确认上一条处理完成后再继续。

当前界面为简体中文。脚本语法、表头识别和同行字段逻辑已通过本地检查；实际 Excel 导入、浏览器交互和扫码设备兼容性仍需在使用环境中验证。大文件容量没有实测保证。
